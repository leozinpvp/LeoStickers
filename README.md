# LÉO STICKERS

## Onde fica cada coisa?

- `index.js`: liga o bot.
- `codigo/`: guarda os outros códigos do bot.
- `figurinhas/`: guarda as figurinhas.
- `logs/`: guarda os registros de funcionamento.
- `backups/`: guarda cópias de segurança.
- `package.json`: lista as ferramentas necessárias.
- `start-bot.sh`: inicia o bot.

As configurações e os dados pessoais ficam neste aparelho e não
devem ser publicados no GitHub.
