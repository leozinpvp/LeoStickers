# Léo Stickers — pacote para análise

Inclui o código atual e os módulos importados, dependências declaradas,
assets, GIFs/vídeos e biblioteca de figurinhas.

## Instalação
1. Instale uma versão compatível do Node.js.
2. Execute `npm install`.
3. Copie `config.exemplo.json` para `config.json` e preencha os dados locais.
4. Faça uma nova vinculação do WhatsApp no ambiente de execução.

## Segurança
Não contém sessão do WhatsApp, `.env`, configuração real, bancos de dados
locais, logs, backups, node_modules ou histórico Git. Nunca compartilhe
`config.json` nem arquivos de sessão.
